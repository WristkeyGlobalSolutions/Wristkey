# 🚀 Quick Preview Guide

## Fastest Way to See the Wallet (2 minutes)

### Step 1: Prerequisites
- Install Node.js 18+ from https://nodejs.org/
- Have a terminal/command prompt ready

### Step 2: Setup
1. **Copy all project files** to a folder on your computer
2. **Open terminal** in that folder
3. **Run these commands:**
```bash
npm install
npm run dev
```

### Step 3: View
- Open your browser to: `http://localhost:3000`
- You should see the WristKey Solana Wallet interface!

## 🎮 What to Try

### Generate a Wallet
1. Click "Generate New Wallet" 
2. See your new Solana address and private key
3. Click "Request Airdrop" to get test SOL

### Test Copy Trading
1. Go to "Copy Trading" tab
2. Try one of these demo addresses:
   - `BpMgN7kJh9qGhBVaGnxF5mXqEpDkzVzYZnBqR8j6XYZW`
   - `FqMgN7kJh9qGhBVaGnxF5mXqEpDkzVzYZnBqR8j6ABCD`
3. Click "Analyze" to see trading metrics

### Send SOL
1. Go to "Send SOL" tab
2. Enter any valid-looking Solana address
3. Enter an amount and click "Send SOL"

### Explore Features
- **Favorites:** Add wallets to favorites for quick access
- **History:** View simulated transaction history
- **Settings:** Rename your wallet
- **Mobile:** Try on your phone - it's fully responsive!
